# P.A PRÊMIOS

Plataforma de campanhas de sorteio com apuração pela Loteria Federal. Requisitos em `SPEC.md`,
plano em `PLAN.md`, decisões em `DECISIONS.md`, comandos e convenções em `CLAUDE.md`.

Início rápido: `pnpm install && pnpm db:up && cp .env.example .env && pnpm db:deploy && pnpm db:seed && pnpm dev`.
